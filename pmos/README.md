# pmos/: what this project maintains for postmarketOS Duranium

Generated by `scripts/pmos-export` from the development worktrees; do not
edit by hand. The image CI (`.github/workflows/images.yml`, `ci/`) builds
the published images from this directory plus upstream postmarketOS.

- `aports/`: our aports, added to upstream pmaports (never replacing one);
  `aports/BUILD` lists the ones the images need. The kernel is torvalds/linux
  at `_base` plus `gtactive3wifi.patch`.
- `pmaports.BASE`: upstream pmaports commit they were last tested on
- `duranium-build/`: our duranium-build commits as a patch series on `BASE`
- `sysupdate-public-key.asc`: the key that signs every channel's SHA256SUMS
- `VERIFIED` (`scripts/pmos-verify`): the aports + duranium-build trees that
  passed on the device; only those reach the public release channels
- `device-samsung-gtactive3wifi/`: the early (pre-Duranium) deviceinfo

See [../docs/RELEASES.md](../docs/RELEASES.md).
